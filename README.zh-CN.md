## 🏛️ 个人简介

现任广东技术师范大学人工智能学院讲师，获中山大学电子信息博士学位。

主要研究**计算机视觉**与**多模态数据融合**的交叉领域在**具身智能（EAI）\车路协同（V2X）\遥感（RS）**方面的应用。致力于面向复杂真实开放场景，构建鲁棒的感知系统。

我与来自*中山大学*、*剑桥大学*、*鹏城实验室*的研究人员保持积极、长期的科研合作。
